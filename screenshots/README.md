# Ảnh chụp giao diện

Chưa có ảnh chụp website được render bằng Chrome. Môi trường triển khai không có công cụ Chrome phù hợp, nên không tạo ảnh giả rồi gọi là screenshot.

Sau khi mở website trên máy, có thể bổ sung ảnh desktop/mobile và Admin vào thư mục này để nộp bài. Các hình trong assets là ảnh sản phẩm/chiến dịch, không phải bằng chứng kiểm thử giao diện.
